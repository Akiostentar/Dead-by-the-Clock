# DEATH BY THE CLOCK
Play as a man who tries to survive off killing people. Made as a project for Terra 

[GAME IS STILL A PROTOTYPE; MANY CHANGES AND POLISHES ARE NEEDED - IT'S GOT A LONG WAY TO GO!]

### Why did we make this project?
This project will allow me to improve my skills in coding a game, this time by myself

### How can you play the game?
1. Visit the game's itch page: https://akioo1997.itch.io/death-by-the-clock; no need to install anything on your local computer.
2. Feel free to take around 5 minutes of your time to just check it out; again, it's still very unfinished, but I'd appreciate if you give it a crack anyway!
